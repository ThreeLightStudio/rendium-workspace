# 에이전트 지침 개선 과정 및 설계 기록 (Agent Improvement Process & Design Record)

[English](./IMPROVEMENT.md) | 한국어

이 문서는 AI 에이전트(Cursor, Cline 등)의 아키텍처 준수율을 높이고 빌드 및 규약 파손을 방지하기 위해, `@rendium/agent-tools` 패키지를 신설하고 에이전트용 지침(Prompt)을 자동화 및 개선하려고 시도한 설계 과정과 핵심 규칙을 기록합니다.

---

## 1. 개선 시도 배경 (Problem Statement)

모노레포 환경에서 작동하는 AI 에이전트는 다음과 같은 고질적인 문제를 일으켰습니다:
- **아키텍처 드리프트 (Architectural Drift)**: 프로젝트의 핵심 의사결정(예: Zustand + Immer 기반의 단방향 데이터 흐름, 1D 평면형 레이어 구조)을 인지하지 못하고 레거시 트리(Tree) 구조나 직접 변이(Mutation) 방식으로 코드를 되돌리려는 경향을 보임.
- **컨벤션 위반 및 린트 파괴**: Biome 린트 규칙이나 TypeScript 타입 명세를 준수하지 않아 빈번하게 빌드가 깨지거나 타입 검사가 실패함.
- **학습 자료 누락**: 에이전트가 코드를 수정하기 전에 필수적으로 선학습해야 하는 온보딩 가이드(`_docs/onboarding`)나 컨벤션 문서를 누락하여 변경 범위를 지나치게 확장함.

이 문제를 해결하기 위해, 에이전트가 작업에 착수하기 전 해당 컴포넌트(Bounded Context)에 최적화된 아키텍처 제약 및 행동 가이드를 주입해주는 **자동화된 지침 생성 도구**가 필요했습니다.

---

## 2. 해결 및 개선 과정 (Improvement Journey)

우리는 에이전트의 워크플로우를 분석하여 다음과 같은 단계로 지침 프롬프트를 동적으로 구성하고 검증하는 파이프라인을 구축했습니다.

### 2.1 1단계: 선언적 규칙 파일 설계 (`.agentrules.yml`)
- 워크스페이스 루트에 공통 규칙을 정의하는 `root` 타입의 규칙 파일을 작성하고, 패키지(`packages/*`, `apps/*`) 내부에는 이를 상속(`extends`)하여 세부 맥락만 오버라이드하는 `package` 타입의 규칙 파일을 정의했습니다.
- 에이전트가 코드 수정 작업 전에 반드시 읽어야 하는 파일 목록인 `required_reading` 메타데이터를 명시했습니다.

### 2.2 2단계: 자동 상속 및 병합 로더 구현 (`ConfigLoader`)
- 파일 I/O와 규칙 분석 로직을 격리하여 `ConfigLoader` 클래스를 설계했습니다.
- 개별 패키지 규칙에서 지정한 `inheritance.extends` 참조 경로를 통해 루트 설정을 가져오고, `principles`, `conventions`, `sops` 항목들을 고유 ID 기준으로 병합(Merge)하는 알고리즘을 구현했습니다.
- Zod 스키마를 통해 구조를 검증하고 중복 ID 등의 오류를 사전에 필터링하는 `AgentRulesSchema` 검증기를 결합했습니다.

### 2.3 3단계: 컨텍스트 기반 프롬프트 렌더러 구현 (`PromptRenderer`)
- Handlebars 템플릿(`src/templates/base_prompt.hbs`)을 도입하여 규칙, SOP, 컨벤션, 그리고 필수 읽기 문서의 실제 상대 경로와 설명을 조합한 마크다운 형태의 프롬프트를 생성했습니다.
- 에이전트에게 **"이 문서들을 읽기 전에는 코드를 편집하지 말라"**는 명시적 제약을 강하게 전달하도록 템플릿의 가시성과 톤앤매너를 가다듬었습니다.

### 2.4 4단계: CLI 래퍼 도구와 워크스페이스 통합
- 개발자가 터미널에서 간단하게 현재 패키지의 에이전트 지침을 조회할 수 있도록 CLI 도구를 패키징했습니다.
- 루트에서 `pnpm agent` 또는 `pnpm agent -- --package-dir <dir>` 명령을 실행하면 즉시 해당 Bounded Context에 최적화된 프롬프트가 출력되도록 연결했습니다.

## 3. 에이전트용 지침 가이드 (Instructions for Agents)

이 저장소에서 작업을 수행하는 AI 에이전트는 아래의 흐름을 반드시 준수해야 합니다.

1. **지침 로드**: 작업이 시작되면 `pnpm agent` 또는 `@rendium/agent-tools`가 제공하는 지침 텍스트를 최우선으로 분석하십시오.
2. **사전 문서 학습**: 규칙 내 `required_reading`에 정의된 문서(예: `visual-layer-provider-onboarding.md`, `typescript.md` 등)에 변경을 가하거나 해당 도메인 코드를 수정하기 전, 해당 문서의 전체 내용을 `view_file` 도구로 열어 완벽히 숙지하십시오.
3. **최소 단위 수정 규칙**: 의사결정의 경계를 지키고, 오직 배정된 패키지 범위 안에서만 안전하게 수정해야 하며 다른 패키지로 수정을 무단으로 넓혀서는 안 됩니다.
